*[CDC]: Change Data Capture — streaming a source database's inserts, updates and deletes
*[SCD]: Slowly Changing Dimension — a modeling pattern for dimension values that change over time
*[PII]: Personally Identifiable Information — data that can identify a specific person
*[ANN]: Approximate Nearest Neighbor — a fast, slightly imprecise vector search algorithm
*[BM25]: Best Matching 25 — a keyword-based document ranking algorithm
*[HMAC]: Hash-based Message Authentication Code — a hash computed with a secret key
*[RBAC]: Role-Based Access Control — granting privileges to roles rather than individuals
*[ABAC]: Attribute-Based Access Control — access policies evaluated against attributes
*[CoW]: Copy-on-Write — a table-format update strategy that rewrites the whole data file
*[MoR]: Merge-on-Read — a table-format update strategy that appends changes to a log file
*[DLQ]: Dead Letter Queue — where messages that fail processing are routed
*[CTE]: Common Table Expression — a named, reusable subquery defined with `WITH`
*[UDF]: User-Defined Function
*[GDPR]: General Data Protection Regulation — the EU's data protection and privacy law
*[CCPA]: California Consumer Privacy Act
*[MTTR]: Mean Time To Resolution — the average time to fix an incident after it is detected
*[TTL]: Time To Live — how long a record or cache entry is kept before it expires
*[UUID]: Universally Unique Identifier
*[KMS]: Key Management Service — a managed service for creating and rotating encryption keys
*[MFA]: Multi-Factor Authentication
*[IAM]: Identity and Access Management
*[OLAP]: Online Analytical Processing — systems optimised for analytical queries over large datasets
*[ADR]: Architecture Decision Record — a short document recording one architecture decision and its reasons
*[MCP]: Model Context Protocol — an open standard for connecting AI applications to external systems
*[RLS]: Row-Level Security — restricting which rows a user or role can see
*[GSI]: Global Secondary Index — a second, differently keyed copy of a DynamoDB table's data
*[IVM]: Incremental View Maintenance — updating a materialized view from each change instead of recomputing it
*[QoS]: Quality of Service — the Kubernetes class (Guaranteed, Burstable, BestEffort) that sets eviction order
